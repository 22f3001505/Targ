# 🥗 TARG — AI-Powered Health & Nutrition Platform

**Targeted AI-based Recipe Generator** — ML-powered recipe recommendations, BMI/BMR analysis, exercise calorie calculator, and macro tracking.

## Features
- 🤖 **ML Recipe Engine** — KNN + Cosine Similarity across 375K+ real recipes
- 💪 **Health Analysis** — BMI, BMR, TDEE using Mifflin-St Jeor equation
- 🏋️ **Exercise Calculator** — 198 MET-based exercises with calorie estimation
- 📊 **Macro Tracker** — Daily nutrition goal tracking
- 📅 **Meal Planner** — 7-day meal planning

## Tech Stack
`Python` `Streamlit` `Scikit-learn` `Pandas` `Plotly`
